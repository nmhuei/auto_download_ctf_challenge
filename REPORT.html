01

Tổng quan & kiến trúc

Bộ công cụ Python tự động hóa vòng đời thi CTF: tải challenge từ platform → dựng workspace chuẩn → quản lý container động → nộp flag → theo dõi tiến độ → xem bảng xếp hạng live. Pipeline chính: URL + Cookie/Token → PlatformDetector → authenticate → fetch_challenges → tải song song → WorkspaceBuilder → SummaryGenerator (SUMMARY.md + challenges.json). File challenges.json là index trung tâm mà dashboard / submitter / instance / ranking đọc lại.

Entrypoints (wrapper + console_scripts)
├── main.py / ctf.py ──────► cli:main            (CLI hợp nhất, 7 nhóm lệnh)
├── submit.py ─────────────► FlagSubmitter       (nộp flag độc lập)
